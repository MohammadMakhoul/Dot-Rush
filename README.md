# 🎯 Dot Rush

**Dot Rush** is a fast-paced 2D game built with Unity where your goal is simple:  
tap the moving target as many times as possible before the timer runs out!

Every successful hit increases your score while the target moves to a new position, changes its size, and switches to a random color.

## 🎮 Gameplay

- ⏱️ You have **30 seconds**
- 🎯 Click or tap the target to score
- 🔀 The target moves to a random position after every hit
- 📏 The target changes size randomly
- 🎨 The target changes color
- ✨ Particle effects appear when hitting the target
- 🔊 Sound effects for hits and Game Over
- ➕ A `+1` animation appears after every successful hit
- 🔄 Restart the game and try to beat your score

## 🛠️ Built With

- **Unity 6**
- **C#**
- **Universal Render Pipeline (URP)**
- **TextMesh Pro**

## 🎯 Goal

Score as many points as possible before the 30-second timer reaches zero.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/MohammadMakhoul/Dot-Rush.git
```

2. Open **Unity Hub**
3. Click **Add → Add project from disk**
4. Select the `Dot-Rush` folder
5. Open the project
6. Open the `Game` scene
7. Press **Play**
